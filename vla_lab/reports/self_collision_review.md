# RB-Y1 자기충돌(self-collision) 검토

## 증상

T5(전자레인지 열기)에서 오른팔이 몸통을 관통한다. 평가 실패 영상에서 팔을 머리 위로 든 채 멈추는 장면도 같은 원인이다.

## 원인 1 — 시뮬레이터: 로봇 자기충돌이 꺼져 있음

| 위치 | 설정 |
|---|---|
| `rby1-sim-isaac/assets/generated/rby1_ready_reach_table.usd` `/RBY1` | `physxArticulation:enabledSelfCollisions = False` |
| `environments/T01~T10.usd` `/World/Robot` | 같은 값 (위 USD를 그대로 사용) |

- PhysX가 로봇 링크끼리의 충돌을 계산하지 않는다. 팔이 몸통·반대팔을 통과해도 막히지 않는다.
- 충돌체 자체는 있다(몸통 5개·팔 링크마다 캡슐, instance 안에 있음). 충돌 제외 쌍은 `arm_3`–`arm_5`(양팔)만 있다.
- **충돌체가 없는 링크:** 머리 3개, `link_torso_3`, `link_*_arm_6`, 그리퍼 본체(`ee_left`/`ee_right`, 손바닥). 자기충돌을 켜도 이 부분은 통과한다.
- `link_*_arm_5` 캡슐은 비균일 스케일(z 0.3)이고, 별도의 convex mesh(`baked_capsule`)가 같이 붙어 있다.

## 원인 2 — 오라클 경로: T5에서 준비 자세로 돌아갈 때 팔꿈치가 가슴을 지남

문을 68° 연 자세에서 손을 떼고 준비 자세(READY)로 돌아가는 구간에서 생긴다. 손목을 되돌리면서 TCP를 직선으로 옮기는데, 이때 IK가 팔꿈치를 몸통 쪽으로 보내는 해를 찾는다. 자기충돌이 꺼져 있어 이 경로가 그대로 실행됐고, 정책도 같은 동작을 배웠다.

## 측정 (`vla_lab/scripts/self_collision_check.py`)

USD 캡슐에 기구학을 적용해 몸통·팔 링크 쌍 112개의 겹침 깊이를 계산했다(0.5cm 초과를 관통으로 셈). 준비 자세는 겹치지 않는다(가장 가까운 쌍도 1.5cm 떨어짐).

| 데이터 | 관통 에피소드 | 관통 step 비율 | 최대 깊이 | 주된 쌍 |
|---|---|---|---|---|
| T5 오라클 시범 | **50/50** | 24.8% | 22.6cm | 위 몸통(`torso_5`)–오른팔 `arm_3~5` |
| T5 평가 (정책) | **50/50** | 41.0% | 23.0cm | 같음 |
| T10 오라클 시범 | 14/50 | 2.1% | 3.3cm | `torso_5`–오른팔 `arm_1~2` |
| T7 평가 | 1/50 | 0.0% | 0.8cm | `torso_5`–왼팔 `arm_4~5` |
| 나머지 task (오라클·평가) | 0 | 0% | 0.3cm 이하 | |

T5 오라클 첫 시범(seed 0): 관통 구간 10.3~13.7초, 가장 깊은 시점 12.7초(`torso_5`–`right_arm_5`, 22.6cm).

## 자기충돌을 켜고 시험 (스크래치 복사본, 레포 미수정)

런타임에 `/World/Robot`의 `physxArticulation:enabledSelfCollisions`를 True로 바꾸고 오라클을 실행했다.

| 항목 | 결과 |
|---|---|
| 오라클 성공 | T1 3/3, T5 5/5, T10 3/3 |
| 관통 | T1·T5·T10 모두 0 (T5 최대 0.3cm) |
| T5 시범 길이 | 206 → 279 frame (팔이 몸통에 막혀 돌아가느라 길어짐, 끝에는 READY 도착) |
| 몸통과 닿지 않는 task도 바뀌는가 | **바뀜.** T1 같은 seed에서 관절 최대 0.023 rad 차이, 길이 ±1 frame. 자기충돌을 켜면 PhysX 계산이 로봇 전체에서 달라짐 |

## 고치는 방법 (결정 필요)

| 안 | 내용 | 장점 | 단점·비용 |
|---|---|---|---|
| A | `vla_lab/scripts/sim_env.py`에서 런타임에 자기충돌 켜기 + T5 복귀 경로 수정 → **10개 task 전부** 다시 수집·변환·학습·평가 | 레포의 환경 파일을 건드리지 않음. 수집·평가가 같은 물리 | 키보드·VR 수집기와 `replay_dataset.sh`는 여전히 꺼진 상태라 새 T5 시범을 재생하면 결과가 다를 수 있음. 약 1.5일 (수집 ~9h, 변환 ~8.5h, 학습 ~3.5h, 평가 ~10h) |
| B | 원본 USD(`rby1-sim-isaac`, `environments/T*.usd`)에서 자기충돌 켜기 + T5 경로 수정 → 전부 다시 | 레포의 모든 도구(키보드·VR 수집, 재생)가 같은 물리 | 환경 파일 수정(다른 레포 포함). 비용은 A와 같음. 기존 키보드·VR 데이터와 물리가 달라짐 |
| C | 오라클 T5 복귀 경로만 고침(몸통을 피해 돌아오기) + 수집기에 자기충돌 검사 추가. 물리 설정은 그대로 | T5만 다시 수집하면 됨 (T5 수집·변환 ~1h, 학습·평가는 다시) | 정책이 평가 중에 몸통을 통과하는 동작을 해도 막히지 않음(평가가 물리적으로 비현실적일 수 있음) |

권장: **B**(가능하면) 또는 **A**. 자기충돌이 꺼진 채로는 정책이 비현실적인 동작으로 성공할 수 있어서, 데이터와 평가 모두에서 켜는 것이 맞다. 추가로, 충돌체가 없는 머리·손바닥·손목 링크에 캡슐을 넣을지도 정해야 한다.
